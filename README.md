FacultyPulse
A data-driven web application built as a hackathon project. This application provides an interactive dashboard designed to streamline data processing, visualization, and user interaction.

Live Demo: [![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://facultypulse.streamlit.app/)

Features
Interactive Dashboard: Navigate through data seamlessly using the clean Streamlit interface.

Data Processing: Built to handle, filter, and compute metrics efficiently.

Accessible UI: Designed for straightforward user interaction without complex setups.

Tech Stack
This project is built using the following core technologies:

Python: The primary programming language used for the backend logic.

Streamlit: Used to build and rapidly deploy the interactive front-end web application.

Pandas: Utilized for data manipulation, analysis, and structuring.

NumPy: Handled numerical computing and array operations.

Local Installation
To run this project on your own machine, execute these commands in your terminal:

Clone the repository: git clone [https://github.com/your-username/HackathonCse.git](https://github.com/your-username/HackathonCse.git)

Navigate into the folder: cd HackathonCse

Install the required dependencies: pip install -r requirements.txt

Launch the application locally: streamlit run Main_Menu.py
